## 📌 Prompt para IA de Design

```
CRIE UMA IDENTIDADE VISUAL PROFISSIONAL PREMIUM para:

EMPRESA: Cell City Informática — Gestão Empresarial
RAMO: Assistência técnica especializada em celulares, notebooks, tablets e equipamentos de informática + Software de Gestão Empresarial (CRM/SaaS)

ESTILO: Corporativo moderno, tecnologia premium, dark mode elegante.
REFERÊNCIA VISUAL: Notion, Linear, VS Code, Arc Browser — minimalista, geométrico, com propósito.

CORES PRIMÁRIAS (MANTER ESSÊNCIA):
- Verde principal: #00C853 (verde vibrante tecnológico)
- Verde claro: #00E676
- Verde escuro: #00B248
- Dourado: #FFCC00 (detalhes premium)

CORES DE FUNDO:
- Preto suave: #0A0B0D
- Cinza escuro: #121418
- Cinza médio: #1A1D23

TIPOGRAFIA ATUAL (pode evoluir):
- Inter (Google Fonts) — pesos 500, 600, 800

FORMATOS NECESSÁRIOS:
1. LOGO HORIZONTAL — "Cell City Informática" + "Gestão Empresarial" + símbolo/ícone
2. LOGO QUADRADA — Apenas o símbolo/ícone da marca (para avatar, PWA, app)
3. FAVICON — Versão simplificada 512×512
4. VERSÃO BRANCA — Símbolo em branco para fundos escuros
5. VERSÃO VERDE — Símbolo monocromático verde

ELEMENTO VISUAL SUGERIDO:
- Um símbolo que represente tecnologia + confiança
- Pode ser: um chip/circuito estilizado, um escudo com checkmark, as letras "CC" entrelaçadas em estilo moderno, ou um ícone abstrato geométrico
- Deve funcionar bem em tamanhos pequenos (favicon) e grandes (outdoor)

DIRETRIZES:
- Estilo limpo, sem ruído visual
- Gradientes sutis (não agressivos)
- Geometria precisa
- Aparência de software empresarial internacional
- Funcionar em tema escuro (primário) e claro (secundário)
- Transmitir: confiança, tecnologia, profissionalismo, inovação

OBSERVAÇÃO: Atualmente a marca é 100% tipográfica (fonte Inter). 
O grande objetivo é criar um SÍMBOLO/ÍCONE que represente a marca visualmente.
```
